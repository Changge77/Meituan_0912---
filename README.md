# 同屋 · 合租生活管家

GitHub Pages 静态交互作品。运行 `npm start`，打开 http://127.0.0.1:4173；运行 `npm test` 验证金额分配、凭证核验、访客审批规则。

包含生活总览、费用 AA（均分/比例/自定义）、支付凭证上传与收款人核验、轮值清洁与换班、物品补货与采购记账、全员访客审批、带版本确认的室友公约以及站内提醒。

本版本没有登录和房东管理页。住户切换仅用于演示，不提供真实身份认证或权限隔离。数据及压缩后的凭证保存在当前浏览器 localStorage；不跨设备同步。请仅使用虚构信息，不上传真实敏感凭证。关闭网页后不发送通知。
